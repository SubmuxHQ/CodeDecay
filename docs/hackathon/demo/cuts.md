27 July 2026.

- repeated full-report text already preserved in the sanitized JSONL;

- private absolute paths, replaced consistently with `<CODEDECAY_CHECKOUT>` and

event: before report, passing shallow test, failing live probe, stated Codex

current-tree CodeDecay rerun, revalidation, and Codex self-review.

evidence. Narration is synthesized from the caption transcript for consistent
audio; Codex's actual text and command events are preserved in the sanitized
