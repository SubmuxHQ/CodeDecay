# CodeDecay Judge Lab

Public, credential-free product lab for issue
[#695](https://github.com/SubmuxHQ/CodeDecay/issues/695).

The risky auth/API and clean-decoy scenarios execute the CodeDecay deterministic
matcher and scoring engine on demand. The weak-test scenario is a precomputed
artifact generated by the full JavaScript analyzer against a temporary
repository fixture. The interface labels that boundary and prints the
reproduction command.

## Safety boundary

`POST /api/run` accepts exactly:

```json
{
  "scenarioId": "auth-api | weak-test | clean-decoy",
  "state": "base | risky | repaired"
}
```

It does not accept repository URLs, uploads, prompts, or commands. All source
material is fixed and inspectable in this repository.

## Local verification

```bash
npm install
npm run lint
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
```

Build with exact source provenance:

```bash
CODEDECAY_SOURCE_COMMIT="$(git rev-parse HEAD)" npm run build
```

Regenerate and verify the checked-in weak-test evidence from the repository
root:

```bash
pnpm judge-lab:evidence
pnpm judge-lab:evidence:check
```
